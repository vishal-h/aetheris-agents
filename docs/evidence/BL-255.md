# BL-255 — the kernel-ceiling decrease-only rule sets zero headroom, so the next backlog filing fails --strict

**The defect.** BL-201 wrote the manifest header's **Kernel ceiling** rule, which says *"a round that
shrinks the kernel lowers it to the new measured size"*. A ceiling at the exact size leaves no room for
`docs/backlog-2026-06.md`, which is itself a kernel row, to grow, and every filed row grows it.
`kernel_budget`'s over-ceiling WARN is not strict-exempt, so the first backlog filing after such a
ratchet turns `drift_check --strict` red, and no filed row explains why.

**Not live at `ab57831`.** The ceiling is 250,000 bytes and the kernel 241,691
(`python3 scripts/drift_check.py --check kernel_budget`), leaving 8,309 bytes of headroom. No round
that reduces the kernel is filed.

**Candidate fixes.** Ratchet to the measured size plus a stated slack, or round up to a stated
boundary. Either way, the rule also says what re-tightens the slack as the kernel shrinks toward the
122,880-byte target.

review packet (bl-201-packet.md, session scratchpad): "the next commit that files a row goes over it,

## Appended 2026-09-21: closed on the arbiter's ruling R3

**The ruling.** At each export boundary, with the kernel measured after all of that boundary's
manifest edits, `candidate = ceil_1000(measured_kernel_bytes + 10,000)` and
`new_ceiling = min(current_ceiling, candidate)`. The 10,000 margin is the headroom this row asked
for. It holds at the boundary that sets the ceiling and is not a standing guarantee: a boundary that
leaves the ceiling unchanged can leave less. The `min` at each boundary is what tightens the margin
again as the kernel shrinks. The full block is under **THE CEILING RATCHET MOVES TO THE BOUNDARY** in
`docs/export-boundaries/rulings.md`. The header's Kernel budget paragraph is rewritten in the
2026-09-21 boundary commit, which follows the commit closing this row.

**Finding: the previous ratchet was never applied.** The kernel fell below the 243,025 bytes the
ceiling was set against at two boundaries. At the second 2026-09-15 boundary it measured 241,086,
and that record says nothing about the ceiling. At 2026-09-17 it measured 239,911, and that record
says *"The ceiling is not lowered here."* without giving a reason. Both figures are the records' own
pre-commit `kernel_budget` readings.
