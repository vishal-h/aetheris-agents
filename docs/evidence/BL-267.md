# BL-267 — worker `:DOWN` does not persist `failed`: the run row can read `running` indefinitely

**The finding.** `Agent.Server`'s worker `:DOWN` handler appends `error{reason: worker_crashed}` and sets in-memory `status: :failed`, with no `Store.upsert_run` (`lib/aetheris/agent/server.ex:564-580`). A later `{:run_complete, :done}` cast is then ignored (`:490-493`), so `runs.status` stays `running` while the server lives. `Aetheris.Sweep` reconciles it only at application start or on `mix aetheris sweep` (`lib/aetheris/application.ex:82-92`).

**Blocks.** BL-266 T1: the stream closes on durable terminal status (`docs/aetheris/backlog/bl-266-run-event-streaming.md` §3 C5), which this run never reaches.
