# BL-275 — `mix aetheris` does not load `config/runtime.exs`, so the documented token override has no effect

**The finding.** `docs/aetheris/playground-api.md` §5 Auth scheme, under **Config source:**
(`:597-614@2d93851`), recommends overriding `:playground_tokens` from
`AETHERIS_PLAYGROUND_TOKENS` in `config/runtime.exs`, and the runbook starts the server with
`mix aetheris server` (`docs/aetheris/runbook.md:159`, `:1005@2d93851`).
`config/runtime.exs:16@2d93851` is the only code that reads that variable — the remaining hits at
`2d93851` are documentation. `lib/mix/tasks/aetheris.ex@2d93851` is a plain `use Mix.Task`
(`:1-3`) with no `@requirements`, and no mix task in the repo declares one, so nothing in the
documented start path evaluates `runtime.exs`.

**Observed** 2026-09-20, during the BL-266 T3 click-through: with the variable set and the server
started the documented way, every token was rejected with 401 until the tokens were set another
way.

**Diagnosed, not isolated.** The 401 is the demonstration. That the absent `@requirements` is its
cause is read off the citations above, and confirming it is the fixing round's.
